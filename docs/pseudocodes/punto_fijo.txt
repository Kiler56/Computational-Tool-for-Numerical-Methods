Begin

Define function fixed_point(g, x0, tolerance, max_iter):
    x ← x0

    For i from 1 to max_iter:
        x_new ← g(x)

        If |x_new - x| < tolerance:
            Print "Converged in i iterations"
            Return x_new

        x ← x_new

    Print "Did not converge"
    Return None

End

Algorithm CompositeTrapezoidal(f, a, b, n)

Input:
    f → function
    a → lower limit
    b → upper limit
    n → number of subintervals

Output:
    Approximate integral

1. h ← (b - a) / n

2. For i ← 0 to n do

       x[i] ← a + i*h

       y[i] ← f(x[i])

   EndFor

3. Integral ← y[0] + y[n]

4. For i ← 1 to n-1 do

       Integral ← Integral + 2*y[i]

   EndFor

5. Integral ← (h/2)*Integral

6. Print results

7. Return Integral

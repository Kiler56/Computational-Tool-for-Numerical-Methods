Begin

Define function secant(f, x0, x1, tolerance, max_iter):

    For i from 1 to max_iter:
        f0 ← f(x0)
        f1 ← f(x1)
        denom ← (f1 - f0)

        If denom = 0:
            Print "Error: division by zero"
            Return None

        x2 ← x1 - f1 * (x1 - x0) / denom

        If |x2 - x1| < tolerance:
            Print "Converged in i iterations"
            Return x2

        x0 ← x1
        x1 ← x2

    Print "Did not converge"
    Return None

End
